# Pastel X Crewvia — CRM Suite Product Deck

A presentation deck showcasing the 13 modules and 61 features of the Pastel X Crewvia CRM Suite.

## Modules

- **Product Management**: Catalogue, variants, and stock.
- **Customer Management**: Profiles, orders, invoices, and discount coupons.
- **Sales Management**: Tracking status from Ready to Dispatched to Delivered.
- **Purchases & Vendors**: Purchase order lifecycle and one-tap reorders.
- **Analytics & Reports**: Live metrics across single or combined branches.
- **Inventory & Branches**: Real-time multi-branch stock management.
- **RBAC & Communication**: Role-based access control and integrated messaging.

## Getting Started

```bash
npm run dev
```

To build for production:

```bash
npm run build
```
